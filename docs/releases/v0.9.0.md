This release adds ItemGroup, SwipeActions, Reorderable and ConversationList, so the kit has twenty-one components. ItemGroup is a labelled list of Items with lines between rows, numbering and an empty message. SwipeActions reveals leading and trailing actions, with a menu and long press as the other ways to reach them. Reorderable moves rows by drag, by a moves menu or from the keyboard. ConversationList groups rows into sections, marks unread ones and virtualises long lists. Each reports one CI line per spec case.

**Known gaps:** WinUI's Reveal mode has no long-swipe commit for a side with several actions. A drag that starts on a Reorderable handle may be captured by the handle's button; a drag from the rest of the row, the moves menu and the keyboard work.

**Checked on:** CI, on `windows-latest` and `ubuntu-latest`. That is Windows Server, not a Windows 11 client (RELEASING.md).
