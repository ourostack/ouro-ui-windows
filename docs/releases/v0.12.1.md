This release puts the kit on nuget.org: `dotnet add package Ouro.UI.Windows` now works with no source to add and no token. The release workflow signs in to nuget.org with its own GitHub identity (Trusted Publishing), so the repository holds no NuGet API key, and it still pushes the same packages to GitHub Packages and attaches them here. The code is v0.12.0's: twenty-six components, no changes.

**Known gaps:** The long swipe on a side with several actions stays a WinUI limit (#71). Table's `rowHref` rows raise a press the app handles, as Windows has no links to follow.

**Checked on:** CI, on `windows-latest` and `ubuntu-latest`. That is Windows Server, not a Windows 11 client (RELEASING.md).
