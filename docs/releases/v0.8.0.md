This release adds Select, Switch and Field, so the kit has eighteen components. Select wraps WinUI's ComboBox. Switch is a button with the Toggle pattern. Field gives a control with no label of its own a label, a description and an error. All three are named by their label, say when they are required, and announce their error. TextField gains a password type, a large size and a clear button. The form specs report one CI line per case.

**Known gaps:** a Select opens a flyout on every device, never a bottom sheet.

**Checked on:** CI, on `windows-latest` and `ubuntu-latest`. That is Windows Server, not a Windows 11 client (RELEASING.md).
