This release adds Table, Message, ReactionBar, MessageList and Composer, so the kit has twenty-six components. Table is a data grid: a caption, column headers and rows, columns a press sorts, rows that are one press, and striped, dense and sticky-header looks. UI Automation reports it as a Table with a Header of HeaderItems, so Narrator reads rows, columns and headers; a sorted header is read as "Serves, sorted descending". Each reports one CI line per spec case.

**Known gaps:** Table's `rowHref` rows raise a press the app handles, as Windows has no links to follow. WinUI's Reveal mode has no long-swipe commit for a side with several actions (#71). A drag that starts on a Reorderable handle may be captured by the handle's button (#72).

**Checked on:** CI, on `windows-latest` and `ubuntu-latest`. That is Windows Server, not a Windows 11 client (RELEASING.md).
