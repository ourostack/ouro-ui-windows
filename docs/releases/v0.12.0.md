This release fixes a Reorderable row that could not be dragged by its handle (#72). The handle no longer takes the pointer, so the list starts the drag, and a click on the handle still opens its "Move down" menu. A real-mouse test on `windows-latest` drags a row from its words and from its handle, and clicks the handle; it failed on the old code and passes now. No components were added: the kit still has twenty-six.

**Known gaps:** The long swipe on a side with several actions stays a WinUI limit (#71). Table's `rowHref` rows raise a press the app handles, as Windows has no links to follow.

**Checked on:** CI, on `windows-latest` and `ubuntu-latest`. That is Windows Server, not a Windows 11 client (RELEASING.md).
