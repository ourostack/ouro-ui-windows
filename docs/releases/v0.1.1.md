A small follow-up to v0.1.0.

- **Packages on GitHub Packages.** `Ouro.Actions` and `Ouro.UI.Windows` are published to `https://nuget.pkg.github.com/ourostack/index.json` (README has the install lines; GitHub's NuGet feed needs a `read:packages` token). They stay attached to the release too. nuget.org comes later.
- **Refusals name the action as a person knows it.** A person-only action refused at the App Action or MCP door now reads "Place order: You can't place an order or pay for the person; only they can..." instead of starting with the command words ("list order: ..."). This comes from core v0.13.1, which the kit now vendors.
- **The pixel check looks under the words.** CI now checks every pixel on each Button's and Badge's middle row against the fill and label it reports, in light, dark and a contrast theme. A test runs it on rows from v0.1.0's contrast screenshots, before and after the backplate fix, and fails the old one.
- **Docs as errors cover the vendored tokens again.** Core v0.12.1 documents every `OuroTheme` parameter, so the `NoWarn CS1573` workaround is gone.

The limits in v0.1.0's notes still hold: the free Windows Server runner has no App Actions runtime, Agent Registry or Mica.
